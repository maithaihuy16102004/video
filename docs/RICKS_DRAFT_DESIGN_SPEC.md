# Ricks-style draft — design and production spec

- Topic: Vì sao ý tưởng thường xuất hiện khi đang tắm?
- Format: 1080×1920, 30 fps, 26 seconds, Vietnamese.
- Direction: editorial cartoon, warm high-contrast palette, energetic but readable.
- Character lock: one host with fixed silhouette, hair, skin, outfit and palette; emotions change without identity drift.
- Motion contract: face + head + arms/body + camera + environment in character scenes; no static portrait fallback.
- Shot grammar: extreme close-up → wide → over-shoulder → orbit medium → insert → Dutch close-up → over-shoulder → low angle → top-down → hero medium.
- Captions: word-progressive, four words maximum on screen, active word receives scale/rotation/color emphasis.
- Audio: dialogue-first; BGM at 0.09; six action-specific SFX cues; deterministic frame timing.
